# Парная проверка агентов через текущий harness

Два свежих субагента с одинаковой унаследованной моделью получили одинаковые 24 вопроса. A получил полные документы, B получил результат ContextIR b200abd. Каждый документ передан один раз с шестью вопросами. Код clients.py и требования к его изменению одинаковы и полны для обоих вариантов.

| Метрика | A: полный контекст | B: ContextIR |
| --- | ---: | ---: |
| Полностью правильные ответы | 24/24 | 23/24 |
| Символы справочного контекста | 20738 | 11284 |
| Независимые проверки изменения кода | 96/96 | 96/96 |

Справочный контекст сокращен на 45.59%. Это не сокращение всех оплаченных токенов: код, инструкции и инструменты также входят в запросы. Фактический usage, стоимость и надежное время полного запроса недоступны. Ускорение не заявляется.

Ошибка B в training4: отбор удалил абзац с 4 291 651 968 и 4 471 435 264 байтами. Агент корректно отказался придумывать отсутствующие числа, но исходная задача осталась нерешенной. В серии Qwen с отдельным вопросом этот абзац сохранялся. Группировка вопросов меняет отбор; проход одиночных вопросов не гарантирует сохранения фактов для пакета.

Оба агента исправили в копиях clients.py проверку целых бюджетов, исключили bool и недопустимые timeout. Родитель отдельно проверил 96 случаев для каждого решения, включая границы, неверные типы, позиционные параметры и HTTP контракт с подменой post_json без сети. Патчи не внесены в основной код: это контрольная задача эксперимента. Она самостоятельна и не требует чисел из отчетов, поэтому ее успешность не доказывает пользу ContextIR для изменений кода, зависящих от внешней документации.

Ограничения: одна пара, без повторов, ручная неслепая оценка, доступ ограничен инструкциями, не файловым sandbox. Ответы и патчи сохранены. Сравнивать абсолютное качество этой пакетной серии с отдельными вызовами Qwen как контролируемый эффект размера модели нельзя.

## Что это означает для LoRA

LoRA может адаптировать модель к чтению представления ContextIR, но не гарантирует восстановление удаленных новых фактов. Текущая ошибка сильного агента возникла до генерации. Сначала нужен отбор, сохраняющий доказательства для каждого вопроса.

После этого разумен отдельный тест: исходная модель с обычной инструкцией, исходная модель с примерами и та же модель с LoRA. Обучающие примеры: вопрос, ContextIR, проверенный ответ с опорой на источник и корректный отказ при отсутствии данных. Документы, проекты и числовые значения теста должны быть отделены от обучения. Обучать нужно чтению новых фактов, не запоминанию текущих 24 ответов. Измерять качество, ложные ответы, забывание, полное время и память. LoRA сама по себе не уменьшает исходные веса и число токенов.

Обучение не запускалось. [Первичная работа LoRA](https://arxiv.org/abs/2106.09685) описывает адаптацию при замороженных исходных весах; полезность для ContextIR остается проверяемой гипотезой.

Полные пакеты, ответы, оценки и патчи: [project_qa_agent.json](project_qa_agent.json).
